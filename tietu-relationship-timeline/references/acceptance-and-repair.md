# 验收与修复

## 第一层：七年爆点结构

以下任一项不满足即失败：

1. 恰好七张，年份从结婚第一年连续到第七年；
2. 第一眼看见第一年的相爱动作，而非普通合影；
3. 七帧共用同一舞台、近似机位和人物；
4. 每年只推进一格关系分隔；
5. 第 K 年亲密度不高于第 K-1 年，无拥抱、对视、共同动作等回弹；
6. 成人间距、背向、注意力分流、空位或分区至少一项逐年增强；
7. 第六年没有和好；第七年存在且是全组最强分隔；
8. 不读正文也能按由近到远排序；
9. 末尾问题能引出个人经历，而不是逼迫站队。

结构失败必须返回距离账本与分镜，不能靠换画风补救。

## 第二层：逐张大图

- 3:4 可打开，人物、舞台和文字无裁切；
- 人物身份、发型、服装主色和固定锚点连续；
- 手、臂、遮挡与物件接触无明显错误；
- 年份逐字正确、唯一且顺序完整；
- 无原账号、水印、平台 UI、评论、解释段落和未要求道具；
- 儿童姿态安全自然，不承担成人冲突的责任。

## 第三层：360px 手机缩略联系表

- 七个年份形成完整节奏；
- 同一舞台像一把尺；
- 第一张最亲密，第七张最分开；
- 任意相邻两张都能指出一个更疏远的可见变化；
- 没有第六年回暖或中途画风漂移；
- 黑色大字或描边年份在缩略图仍可辨；
- 故事不靠正文才能成立。

## 第四层：风格档案

### A 型

暖米白纸感、大留白、深棕粗线、简化人物、低饱和点色成立；无精装房间、电影光、写实脸和复杂衣褶。

### B 型

黑色大年份清楚；人物近景、动作和克制表情可读；轮廓利落、填色干净、背景简洁；无暴怒、露骨手机内容、物化或性别羞辱。

### C 型

逐项对照任务开始时写下的风格卡，不得临时改标准。

## 修复记录格式

记录“失败层 / 失败帧 / 编辑区域 / 缺陷 / 目标 / 冻结项 / 修后亲密分”。

- 年份错字、手部或局部道具错 → 定点修图；
- 人物或舞台漂移 → 以上一张通过图重生该帧；
- 第六年和好、亲密度回弹或缺第七年 → 重做对应分镜与图，不算局部瑕疵；
- 第七年不够远 → 加强原创分区，但保留同一舞台，禁止照搬两床结尾；
- 整体风格错误 → 重生该帧。

修后必须重新打开大图和七图联系表。没有执行的能力写“未实测”，不得预填通过。
