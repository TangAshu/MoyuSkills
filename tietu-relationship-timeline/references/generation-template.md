# 七年渐远生图模板

方括号必须全部具体化后再发送给图像工具。

## 第一帧

```text
用途：婚姻七年渐远组图第 1/7 张，3:4 竖版。
创作设定：虚构生活观察，不对应真实家庭。
角色卡：[夫妻发型、服装主色、体型关系；后续儿童若出现则单列]。
舞台卡：[原创固定场景、近似机位、三个固定锚点]。
本帧唯一事件：[主动靠近、互看、共同完成某动作]，这是全组最高亲密基线。
精确且唯一文字：“结婚第一年”。
视觉档案：[A/B/C 的完整可观察参数]。
禁止：原参考人物、原床景、原动作组合、水印、平台 UI、账号、解释文字。
```

## 第二至第七帧

```text
以上一张通过图为连续性参考。这是第 [K]/7 张。
冻结：人物身份、固定舞台、近似机位、画布比例、色板、线条、年份位置和视觉档案。
唯一文字改为：“结婚第[K]年”。
上一年亲密分：[X]；本年亲密分：[X-1]。
只推进一个不可逆变化：[成人间距/身体朝向/视线/共同动作/中介物/空位/分区]。
本帧必须在至少一个可见指标上比上一帧更疏远，且不得在其他指标上明显补回亲密。
只新增或移除：[一个关键物或一个关键动作]；旧阶段动作不要无意义累积。
不要换场景、换人物、换画风，不要让夫妻重新靠近、相视微笑、拥抱或共同完成动作。
```

## 第六年硬约束

```text
第六年必须比第五年更远：使用背向、不对视、错峰、宽空隙或空位中的一种。
禁止和好、牵手、共同举杯、重新并坐或正向团圆暗示。
```

## 第七年硬约束

```text
第七年必须存在且为全组最强分隔。
在同一舞台中形成两个明确视觉区：例如餐桌两端+中央空椅、沙发两侧+大空位、玄关错峰+一方离场痕迹。
不得照搬对标的两床构图；不得用突然离婚、暴力或哭闹替代日常疏远。
```

## 定点修图

```text
只编辑第 [K] 帧的[明确区域]：把[回弹/错字/手部/道具/连续性缺陷]改成[可观察目标]。
冻结：人物、舞台、机位、其余动作、年份和全部风格参数。
修后亲密分不得高于上一年；第七年必须仍是最强分隔。
不要新增人物、文字、水印或背景陈设。
```

中文文字不稳定时，先生成完全无字图，再用有权使用的排版工具统一加字，并记录真实方法；乱码、缺字和错年号不能放行。
