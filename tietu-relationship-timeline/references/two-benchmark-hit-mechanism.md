# 双对标爆点模型

## 结论与证据边界

两个案例都显示或由用户提供“10万+”，但没有后台曝光、点击率、完读率或对照实验。以下是两个高表现案例共享的、值得复用验证的创作机制，不是因果证明，也不承诺流量。

## 爆点不是“床”，而是七年单向渐远

| 层 | 两个案例的共同结构 | 吸引力作用 |
| --- | --- | --- |
| 母题 | 婚姻第一年至第七年 | 已婚人群一秒判断“与我有关” |
| 首图 | 第一年的明确相爱与身体靠近 | 建立最高亲密基线，放大尾图落差 |
| 数字承诺 | 七个年份完整出现 | 熟悉的“七年之痒”语义与滑完预期 |
| 固定坐标 | 同一私密场景、近似机位、同一对夫妻 | 像用一把尺测量关系，降低比较成本 |
| 单向变化 | 每年新增一格障碍、分心、背向或空白 | 让读者追问“下一年还会远到哪里” |
| 空间隐喻 | 贴近 → 中介进入 → 注意力分流 → 背向 → 分区 | 把抽象疏远变成不用解释的画面 |
| 终点回报 | 第七年最强分隔 | 兑现年份与首尾反差，完成故事 |
| 评论入口 | 手机、孩子、睡眠、家务等普通细节 | 触发“我们在哪一年”的自我投射 |

因此，缺第七年、在第六年和好，或任一年比上一年更亲密，都会破坏该品类最关键的阅读承诺。

## 两个案例的差异只在表现层

### 案例 A：纸感克制

- 米白纸感、大留白、深棕粗线、低饱和；
- 人物简化，情绪不靠脸部夸张；
- 主要用身体距离、朝向、被子和空白分区；
- 第一眼较安静，适合“原来距离是慢慢出现的”。

### 案例 B：清线漫画

- 数字漫画更干净，近黑轮廓更利落；
- 人物更近、更大，脸和手部动作更易读；
- 顶部大号黑色“结婚第X年”；
- 冲突线索更显性，适合“一眼看懂这一年变了什么”。

案例 B 的特定手机内容和强烈表情不属于必须保护的爆点，且有物化和过度归因风险。新版只保留“节点读得快”，不复制具体内容。

## 创作时保护什么、改变什么

必须保护：七帧完整年份、第一年最亲密、同一舞台、逐年不可逆、普通生活细节、第七年最强分隔。

必须重设计：人物、家具、场景、物件、每年的具体动作、文字造型、色板和最后的分隔方式。可以从床换成餐桌、沙发、玄关或车内，但不能照搬“孩子—手机—背对—两床”的原顺序。

## 新题生成公式

```text
一种常见夫妻生活
+ 一个可连续复现的私密舞台
+ 第一年最高亲密基线
+ 六次不可逆的小幅疏远
+ 第七年原创的最强空间分隔
+ 一个“你们到了哪一步”的低门槛问题
```

画风负责入口气质；七年单向渐远负责故事张力。两者不得混为一层。
