# 贴图号·婚姻七年渐远组图

`tietu-relationship-timeline` 把婚姻主题创作成七张独立 3:4 竖图：从“结婚第一年”到“结婚第七年”，同一对夫妻、同一生活舞台和同一画风保持连续，亲密度只减不增，第七年形成全组最强的视觉分隔。交付内容还包括五个标题、中文正文、分镜账本、生图指令和真实质检记录。

## Codex 安装与调用

1. 下载并解压 Codex ZIP。
2. 把 `tietu-relationship-timeline` 文件夹放到项目或个人的 `.agents/skills/` 中。
3. 确认最终路径为 `.agents/skills/tietu-relationship-timeline/SKILL.md`；若没有立即发现，重启 Codex。

```text
请使用 $tietu-relationship-timeline，以“婚后两个人越来越只聊孩子”为主题，创作从结婚第一年到第七年的原创七帧关系组图。保持同一场景和同一画风，让亲密度逐年下降且不能回弹，第七年分隔最强；真实生成并复看七张图，再交付5个中文标题、完整正文、分镜账本、生图指令和质检记录。
```

## WorkBuddy 安装与调用

下载 WorkBuddy ZIP 后直接上传到 WorkBuddy 开放平台或客户端，不要先解压。平台显示名为“贴图号-婚姻漫画7年渐远图文创作”。

“试试这样问我”可填写：

> 请以“婚后两个人越来越只聊孩子”为主题，创作结婚第一年至第七年的原创七帧婚姻关系组图，并配好5个标题、中文正文和真实质检记录。

## 创作边界

- 七年渐远是创作模型，不代表所有婚姻，也不用于判断出轨、冷暴力、抑郁或必然破裂。
- 不复制对标内容的原题、人物、动作序列、具体家具、正文、评论、水印或账号界面。
- 不承诺阅读量、固定完成时间或自动发布；缺少生图、复看或保存能力时必须如实标记未实测。

完整结构合同、生产流程和验收规则见 [SKILL.md](SKILL.md)。
